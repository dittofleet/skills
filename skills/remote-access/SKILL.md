name: remote-access
description: User-invoked at the start of a remote session.
---

The user is accessing this session from a remote machine, not the machine you are running on.

Since the user cannot test the results directly, it is highly recommended that you provide a demo of your work via screenshots, a video, or something else.

To share any non-image or non-video file, use the dropcube skill and reply with the link. For a short text file, it may be simpler to just print its contents in your reply instead.
